# Agent guide

pnpm monorepo (Node 24, pnpm 10). Read this first; per-package details live next to the code.

## Layout

| Path | What | Deploy | Notes |
|------|------|--------|-------|
| `apps/web` | Next.js 16 dashboard (CrUX, PageSpeed, Lighthouse viewer, `/stream`) | Vercel | Read `apps/web/AGENTS.md` (Next.js differs from training data), `apps/web/CONTEXT.md` (glossary) |
| `apps/api` | Void API on Cloudflare Workers (D1, KV, R2, queues, cron) | `void deploy` / wrangler | Holds Google keys; web proxies via `WORKER_URL` + `WORKER_API_KEY` |
| `packages/cli` | `@maxwellcohen/web-perf-report` CLI + stdio MCP server (`audit_site`, `analyze_report`, `measure_stream`) | npm (release.yml on version bump) | Calls web `/api/agent/*` |

Agent-facing HTTP surface lives in `apps/web/src/app/api/agent/{report,stream,trace}` and `apps/web/src/lib/agent/`; `/llms.txt` is generated by `apps/web/src/app/llms.txt/route.ts`.

## Commands (repo root)

| Task | Command |
|------|---------|
| Install | `pnpm install` |
| Dev | `pnpm dev:web` / `pnpm dev:api` |
| All checks (typecheck, lint, tests) | `pnpm check` |
| Typecheck | `pnpm typecheck` (web), `pnpm typecheck:api`, `pnpm typecheck:cli` |
| Tests | `pnpm test`, or one package: `pnpm --filter web test`, `--filter api test`, `--filter @maxwellcohen/web-perf-report test` |
| One test file | `pnpm --filter web exec vitest run path/to/file.test.ts` |
| Lint / format (web) | `pnpm lint`, `pnpm --filter web fmt` |
| Build | `pnpm build:web` / `build:api` / `build:cli` |

Web-only extras: `pnpm --filter web test:e2e` (Playwright), `knip`, `dupes`, `db:generate` (Drizzle migrations in `apps/web/migrations`). API migrations: `pnpm --filter api db:generate`.

## Environment

- `apps/web/.env` from `apps/web/.env.example`; needs `WORKER_URL`, `WORKER_API_KEY`. Unit tests don't need real secrets.
- `apps/api` secrets via `void secret put` (`PAGESPEED_INSIGHTS_API`, `WORKER_API_KEY`).
- Never commit `.env*` (except `.env.example`). Don't print secrets.

## Conventions

- Tests are colocated (`*.test.ts[x]`, Vitest). Add/adjust a test with behavior changes; run the affected package's tests before finishing.
- Web uses oxlint/oxfmt (not eslint/prettier) and `tsgo` for typecheck.
- CI path-filters per package (`.github/workflows/ci.yml`); markdown-only changes skip CI.
- Don't hand-edit generated files: `apps/*/migrations/meta`, `pnpm-lock.yaml`, `apps/api/void.lock.json`, `next-env.d.ts`.
- Changing the CLI's published behavior: bump `packages/cli/package.json` version (merging to main publishes).
- Keep PRs small; merge `origin/main` before pushing.
